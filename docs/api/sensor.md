# `wrs.sensor`

Prefer these in-house utilities over trimesh / scipy / open3d / fcl. Auto-generated by `tools/gen_api_index.py` (static ast scan); re-run after adding functions.

## `wrs.sensor.camera_model`
_Rectified pinhole calibration: +X right, +Y down, +Z forward, meters._

- **class `CameraModel`** — Pinhole intrinsics in pixels; integer (u, v) denotes a pixel center.
  - methods: `matrix`, `from_fov`, `deproject`, `project`, `ray_lut`, `render_model`, `remap_lut`

## `wrs.sensor.d405_noise`
_Vectorized, stateful hole/value stereo corruption with no learned dependency._

- `depth_edges(depth, threshold_m=0.005)` — Return edge mask, horizontal-edge mask, and Chebyshev distance in pixels.
- `build_noise_cues(clean_depth, config, camera_model, baseline_m, *, rgb=None, normals=None, semantic_ids=None, material_difficulty=None, motion_px=0.0)` — Build reusable geometry/appearance features, all in the input image grid.
- **class `CorruptionReason`**
- **class `D405NoiseState`** — Sensor-grid history; disparity history is a unit-normal AR field.
- **class `D405NoiseResult`**
- **class `D405HoleNoiseModel`** — Replaceable probability model: probability(cues, config) -> (H,W) [0,1].
  - methods: `probability`
- **class `D405ValueNoiseModel`** — Replaceable value model; small precision and gross donor errors stay separate.
  - methods: `precision`, `mismatch_probability`, `mismatch`
- **class `D405NoiseModel`** — Compose replaceable hole/value models with spatial and temporal sampling.
  - methods: `reset`, `get_state`, `set_state`, `apply`

## `wrs.sensor.d405_noise_analysis`
_Offline metrics and conservative initial fitting for real/simulated depth sequences._

- `load_depth_recording(path, *, depth_unit_m=None)` — Read metric NPY/NPZ, or sorted Z16 PNG files in a directory.
- `temporal_reference(depth)` — Static-scene temporal median; never-observed pixels remain zero.
- `analyze_depth_sequence(depth, *, reference=None, known_depth_m=None, evaluation_mask=None, edge_threshold_m=0.005, edge_band_width_px=3, outlier_threshold_m=0.01)` — Compute quality/morphology metrics with explicit denominator and reference metadata.
- `fit_noise_config(depth, *, fx=None, baseline_m=None, known_depth_m=None, reference=None, evaluation_mask=None, base_config=None)` — Estimate initial parameters, retaining unidentifiable gains as heuristics.
- `write_colored_ply(path, points, colors)` — Write binary little-endian XYZ/RGB PLY without an extra point-cloud library.

## `wrs.sensor.d405_noise_config`
_Serializable analytic D405 profiles; values are simulation defaults, not factory data._

- `load_noise_profile(path)` — Load the small versioned profile format, without executable objects.
- **class `D405NoiseConfig`** — Raw-like stereo corruption controls (meters and image pixels).
